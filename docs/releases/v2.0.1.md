# 保填 v2.0.1

这是 Agent 2.0 的连续填写状态修复版本，不改变资料格式和 API 配置。

## 修复

- 已填写且受保护的必填字段不再因为模型返回一条“无需覆盖”的解释性说明而暂停；只有真正未解决的必填字段、目标字段或被拒绝动作仍会阻止连续填写。
- 页面签名变化时立即清除上一页 Agent 断点，避免材料页继续显示上一页“获奖情况”的计划、计数或错误。
- Agent 必须暂停时，面板现在显示实际的中文确认原因，而不是 `Agent plan contains ... manual review` 这类英文总括信息。
- 本地校验过滤为“仅建议最终复核”的说明后，Agent 面板同步展示过滤后的待确认数量，不再出现本页已核对但仍显示旧待确认项的状态矛盾。
- 修正“学术成果”和“本科期间奖励情况”的资料边界：学术成果会检索科研训练、论文、专利和学科竞赛；“何时何地何原因受过何种奖励”只检索荣誉奖励，不再混入学科竞赛。
- 补全嵌套表格的外层题干采集。即使“时间 / 地点 / 内容”位于内层重复行，Agent 也能看到外层的完整问题和“不得含有 `|`、`#`”等限制，不再只凭三个通用列名猜测资料类型。
- 单个学术成果长文本框会获得一份带逐项字段来源的综合资料，使中转模型可以在同一次计划中组织多项科研成果，同时仍能通过本地证据校验。
- 学科竞赛、论文、专利等明确页面继续使用各自资料组；非 Agent 的本地投影与语义安全过滤同步采用相同边界。
- Agent 协议升级到 v7。升级后旧页面计划和旧断点会自动失效，避免继续复用已经混入竞赛记录的奖励页缓存、旧的保守空计划或缺少完整题干的页面快照。

## 安全边界

本次修复没有放宽自动操作权限。保填仍不会点击最终提交、确认报名、承诺书、验证码、支付、志愿或导师选择。真正未填写的必填项仍会暂停并要求本人处理。

## 升级

下载 `baotian-2.0.1-chrome.zip` 或 `baotian-2.0.1-firefox.zip`。使用解压缩扩展的用户可将新构建覆盖到原加载目录，再在扩展管理页点击“重新加载”并刷新报名网页；原目录不变时，本地资料和 API 配置会继续保留。

## 验证

- 为“保护值解释被误判为阻塞”“跨页保留旧 Agent 断点”“英文总括原因”“学术成果与荣誉奖励混用”“旧协议断点复用”添加了回归测试，并在修复前确认测试失败、修复后确认转绿。
- 在复旦真实报名页面使用用户配置的中转 API 做了隔离测试：锁定“下一步”并临时清空当前 DOM 后，奖励页只检索 12 条荣誉奖励，生成 12 个整行动作，36 个单元格全部通过写后回读；测试结束恢复原有 54 个页面值，未执行保存、下一步或提交。
- 同一真实系统的学术成果页会把科研训练和具备明确本人排名或角色的学科竞赛转换为“时间 / 发表刊物或出版社 / 标题 / 作者排名”结构；缺少明确排名依据的记录会保留人工复核，不凭姓名顺序编造排名。
- 完整自动化测试、TypeScript 编译、Chrome/Edge 构建和 Firefox 构建均作为发布门禁。
