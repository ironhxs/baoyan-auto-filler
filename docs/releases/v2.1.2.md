# 保填 2.1.2

2.1.2 完成此前留到最后的动态级联选择闭环。院校、地区、专业等多级控件现在由本地安全执行器和受约束 Agent 协同处理，同时保持“不提交、不猜节点、不绕过校验”的边界。

## 主要更新

### 稳定字段身份与 DOM 重绑定

- 打开动态控件前保存 `id`、`name`、`prop`、`xtype`、`caption`、字段标签、分组和控件类型；
- Vue、React、Element UI 等框架销毁旧 input 后，按稳定证据重新查找当前唯一节点；
- 多个候选得到相同分数时停止重绑定，不会猜一个节点继续；
- 普通下拉、级联和日期回读也复用捕获的不可变身份。

### 本地优先的级联策略

执行顺序为：

1. 已验证路径缓存；
2. 页面当前值回读；
3. 当前层精确匹配和唯一代码前缀匹配；
4. 完整行政区或显式路径逐层拆分；
5. 当前控件内搜索；
6. Agent 从当前可见候选白名单中选择下一步；
7. 最多 60 个首级分支的有界本地探索；
8. 无法可靠确定时交给人工。

例如资料只保存“合肥工业大学”，页面要求先选省份时，Agent 只能从页面当前显示的省份候选中选择；选择后执行器重新观察学校列表，找到页面真实标签后再点击和回读。

### 受约束 Agent 动作

- 请求只包含当前字段题目、说明、目标值、已选路径和当前层可见候选；
- Agent 只能返回 `select_visible_option` 或要求人工处理；
- 返回值必须能唯一映射到当前可见候选，候选外内容直接拒绝；
- 不接受脚本、任意选择器、XPath、坐标或页面按钮；
- 单字段最多进行两次 Agent 决策，单次候选请求 15 秒超时，API 不可用时仍可继续本地安全策略；
- Responses、Chat Completions 和用户设置的 Fast 模式继续沿用现有配置。

### 路径缓存与回读

- 只有最终页面值与目标一致后才写入缓存；
- 缓存按网站路径、稳定字段身份、目标值和首级结构校验；
- URL 查询参数与 hash 不进入缓存，避免保存令牌或项目参数；
- 首级候选结构变化、路径失效、回读不一致或超过 30 天时自动作废；
- 缓存只保存页面候选路径，不保存登录状态、Cookie 或 API Key。

## 安全限制

- 最多 8 层级联、2 次 Agent 决策、60 个首级探索分支；
- 页面候选白名单不唯一、节点无法唯一重绑定或连续回读失败时停止当前字段；
- 停止一个字段不授权提交、暂存、下一步、志愿/导师选择、承诺书、验证码、支付或删除操作；
- 学校和手机号等精确字段不会使用可能混淆相近名称的任意模糊点击。

## 验证范围

发布前执行全部离线回归、TypeScript 编译、Chrome MV3 构建、Firefox MV2 构建和双浏览器打包。中山大学系统在本轮验收时处于维护状态，因此 2.1.2 不把该站点写成“已完成在线端到端验收”；待站点恢复或用户提供其他可用真实级联页面后，再进行不提交的真实填写与回读验证。
