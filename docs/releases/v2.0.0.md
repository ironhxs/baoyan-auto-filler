# 保填 v2.0.0

保填 2.0 是一次面向复杂报名表单的架构升级：在保留 1.x 本地确定性匹配、手动速填、材料管理和连续任务能力的基础上，引入运行在浏览器扩展内的页面级填写 Agent。

## 主要更新

### 页面级 Agent

- 读取当前页面真实的字段、分组、行列、选项、格式示例、禁止字符和长度限制；
- 只检索与当前页面相关的本地资料记录，减少无关敏感信息外发；
- 使用用户配置的 OpenAI 兼容中转 API 生成 JSON 填写计划，并在扩展本地执行严格 Schema、页面指纹、资料证据和动作白名单校验；
- 同时支持 Responses 与 Chat Completions；Responses 请求关闭服务端存储；
- Fast 模式继续支持 `service_tier: "fast"`；
- Agent 使用流式普通 JSON，避开部分中转对服务端结构化输出支持不稳定的问题；认证、限流、上游 502 或网络错误不会触发换线或盲目重试。

### 复杂表格与跨网站结构转换

- 多列重复记录按整行原子执行，模型返回顺序不会改变网页列顺序；
- 支持将竞赛/奖励资料转换为“时间、地点、内容”等学校自定义结构；
- Agent 会根据相邻列共同判断学校的填写口径：地点使用地理范围或可核实的授奖机构，例如将“华东区域赛”归一为“华东地区”、“安徽赛区”归一为“安徽省”，不把赛制名称机械复制为地点；
- 内容按科研项目、竞赛作品、团队奖或个人荣誉自然成句，不使用统一括号模板；原资料缺少月份或城市时会暂停确认，不凭空补全；
- 支持项目、论文、专利、奖励等不同网站常用投影；
- “学习与工作履历”与科研训练、实习实践、社会工作严格隔离；
- 当前页没有对应重复表格时直接跳过，不再用其他资料组阻塞基本信息页；
- 页面真正存在表格但没有安全新增入口时才暂停等待人工处理。

### 执行、回读与修复

- 只执行页面快照中真实存在、且能由已保存资料提供证据的动作；
- 拒绝模型编造的字段、资料 ID、跨组来源、未知动作和提交/点击动作；
- React / Vue 等受控输入框写入后等待框架回写；
- 每个字段都从网页回读，整行任一列失败即视为未完成；
- 保护用户手工修改值；
- 失败项最多进行两轮定向修复，仍失败则暂停；
- 支持失败字段定位、只重试失败项和重新规划本页。

### 缓存、断点和多任务

- 每一步保存本地 Agent 断点，暂停后恢复不会丢失计划与已验证结果；
- 大型重复表格按完整资料行分批规划，并显示“已完成 N/M 批”；Chromium 构建通过隐藏扩展模型桥承载长请求，避免 MV3 后台回收造成永久卡在“规划中”；
- 同页计划缓存 30 分钟；页面、资料、模型、协议、Fast 设置变化后自动失效；
- 复杂自动填写页直接进入页面 Agent，不再先触发旧逐字段 AI，避免重复请求；
- 页面切换后旧动作不会重放；
- 多学校、多项目继续使用相互独立的任务记录，并可在统一审核中心汇总。

### Agent 状态面板

- 展示计划动作、回读一致、保留手工、待确认、失败、重试和缓存状态；
- 不显示 API Key、密码、身份证号、手机号或模型原始响应；
- 当前网站和当前页面优先展示，批次信息保持为次级入口。

### Firefox 隐私声明

- Firefox 安装包准确声明 AI 请求涉及的身份资料、API 认证、当前网址和网页内容数据传输；
- 最低版本设为 Firefox 140，使用浏览器内置的数据传输同意流程；
- Chrome / Edge 清单不包含 Firefox 专属声明。

## 保留的安全边界

保填仍然不会自动执行以下操作：

- 最终提交或确认报名；
- 支付；
- 验证码；
- 勾选承诺书；
- 志愿、专业方向或导师选择；
- 无法回读验证的危险控件。

材料可以先由系统匹配并写入文件框，但连续任务会暂停，要求本人查看“题目名称 + 文件名”并预览确认后才继续。网页中已经上传的照片或材料同样会原样保留并进入预览门禁；对于被服务器错误标记为通用二进制类型的图片，只有文件头确认是受支持图片格式后才会展示。

## 已知边界

- Word / PDF 个人资料 AI 导入本版不开发；
- 极少数完全自绘、无可访问语义的控件仍需要手动速填；
- 学校后端的隐藏校验可能无法在填写前获知，最终提交前必须由本人逐项检查。

## 升级方式

从 Release 下载：

- `baotian-2.0.0-chrome.zip`
- `baotian-2.0.0-firefox.zip`

为了保留资料和 API 设置，请把新文件覆盖到原来的解压目录，在扩展管理页点击“重新加载”，然后刷新报名网页。不要先删除旧扩展。升级前仍建议在工作台导出一次 JSON 备份。

## 验证

2.0.0 发布前运行 34 组自动化测试，覆盖资料模型、跨结构投影、长问题、本地匹配、复杂重复记录、弹窗/抽屉、学校选择器、页面恢复、多任务、材料审核、最终检查、两种 API 协议以及 Agent 的快照、检索、计划解析、策略、执行、回读、缓存、恢复、激活条件和状态面板；Chrome/Edge 与 Firefox 构建均通过。

另在真实报名页面进行了只读边界内的填写验证：18 条奖励记录均生成完整整行计划，48 个有充分资料依据的单元格通过网页回读；两条仅有年份而页面强制年月的记录共 6 个单元格被主动留待确认。测试过程中没有点击保存、下一步、确认或最终提交，页面原值在验证后已恢复。网页已有照片的预览与确认门禁也通过真实页面验证。
