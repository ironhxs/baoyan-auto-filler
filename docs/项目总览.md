# 项目概览

## 是什么

保填是一个 Chrome 浏览器插件，用于减少推免报名系统中的重复填表。用户只需录入一次资料，插件优先通过本地匹配，并可选使用 LLM 补充低置信字段。

## 目标人群

- **高校学生** — 申请夏令营、研究生推免、实习、奖学金等，每个系统都要求填写相同信息
- **基层公务员** — 需要向不同部门提交类似报表，部分岗位年填报量超 2000 份，字段命名不统一

## 核心痛点

现有自动填充工具依赖关键词匹配（如 label 里包含"姓名"就填名字），在以下场景失效：
- 字段表述多样："姓名" vs "真实姓名" vs "您的名字"
- 用户存储的字段标签与表单不完全一致
- 文件上传需要按不同顺序排列图片 — 每个系统的要求都不一样

## 竞品分析

| 类别 | 代表产品 | 不足 |
|------|---------|------|
| 关键词填充工具 | uTools、AutoDog | 无语义理解，匹配僵化 |
| AI 简历填充 | JobCopilot、Canyon | 数据存平台服务器，仅针对求职场景 |
| PDF 工具 | iLovePDF、Drop | 独立工具，与填表流程割裂 |
| 政府层面改革 | "一表通" | 自上而下推进慢，覆盖范围有限 |

## 差异化优势

1. **LLM 语义匹配** — 理解字段意图而非关键词，"请输入您的真实姓名"能准确映射到姓名字段
2. **数据完全本地存储** — 用户信息存在 `chrome.storage.local`，除字段匹配查询外不上传任何数据
3. **一体化工作流** — 表单填充 + 图片管理 + PDF 拼装，一个工具搞定，而非多个独立工具拼接
4. **个人数据主权** — 对处理敏感信息的公务员群体尤为关键
